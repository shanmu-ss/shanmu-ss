## 🚀 Featured Projects

### 🖱️ PointCast — On-Device VLM Grounding for Accessibility
An accessibility tool that lets users control GUIs by voice, fully on-device.
- **LoRA fine-tuned Qwen2.5-VL-3B** for UI element grounding → **85.5% Top-1 accuracy on ScreenSpot-V2**
- Benchmarked small VLMs (Qwen2.5-VL, PaliGemma) against GUI-specialist models
- On-device speech I/O with **Moonshine** (STT) + **Kokoro ONNX** (TTS), Gradio interface
- `PyTorch` `Hugging Face` `LoRA/PEFT` `ONNX` `Gradio`

### 🚦 UrbanMove — Real-Time Urban Mobility Platform on AWS
Streaming data platform for live urban mobility analytics.
- Event ingestion with **Kafka**, stream processing with **Flink**, APIs on **FastAPI** with **Cognito** auth
- Entire stack (**79 AWS resources**) provisioned with **Terraform**
- `AWS` `Kafka` `Flink` `FastAPI` `Terraform`

### 🏥 Patient Readmission Prediction Pipeline
End-to-end ML pipeline predicting hospital readmissions.
- **Snowflake** data layer → **SageMaker Autopilot** training → infra as code with **Terraform**
- `AWS SageMaker` `Snowflake` `Terraform` `Python`

### 🧠 Brain Tumor MRI Classification
Comparative study of CNN architectures for MRI tumor classification.
- Trained and evaluated **GoogLeNet, ResNet, EfficientNet, SqueezeNet** in PyTorch with a full evaluation report
- `PyTorch` `Computer Vision` `Transfer Learning`

### 📐 VAE Paper Reproduction — *Kingma & Welling (2013)*
From-scratch reproduction of *Auto-Encoding Variational Bayes* on MNIST and Frey Face.
- `PyTorch` `Generative Models` `Research Reproduction`

### 🌫️ PM2.5 Air-Quality Forecasting
Time-series forecasting of PM2.5 pollution around Vitry-sur-Seine using OpenAQ v3 data.
- STL decomposition + ARIMA modelling
- `Python` `statsmodels` `Time Series`

### 👟 StepSquad — Fitness Challenge Dashboard · [live ↗](https://stepsquad.shanmu.me)
Team step-challenge dashboard with Notion sync, self-hosted on EC2.
- `React` `Express` `SQLite` `Notion API` `AWS EC2`
